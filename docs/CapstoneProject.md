# AI Agents: Intensive Vibe Coding Capstone Project

> **Put your course learning into action by building an AI agent that solves a real-world problem, helps people, or improves everyday life.**

---

# Overview

The **AI Agents: Intensive Vibe Coding Capstone Project** invites participants to build an AI agent using the concepts, tools, and best practices learned in **Kaggle's 5-Day AI Agents: Intensive Vibe Coding Course with Google**.

Participants will create a practical, real-world solution demonstrating how AI agents can:

- Automate tasks
- Assist users
- Solve business challenges
- Improve everyday workflows

Submissions should showcase both the project's value and technical implementation through:

- Kaggle Writeup
- Public codebase
- Video demonstration
- Public project link

Projects may be entered into one of four tracks:

- Agents for Good
- Agents for Business
- Concierge Agents
- Freestyle

Projects will be evaluated on innovation, solution design, communication, and the effective application of course concepts and agent technologies.

# Description

AI agents are rapidly changing how we interact with technology, enabling systems that can reason, take action, and complete complex tasks on behalf of users.

In this capstone project, you'll apply the concepts, tools, and techniques learned throughout Kaggle's **5-Day AI Agents: Intensive Vibe Coding Course with Google** to build an agent that solves a meaningful real-world problem.

Examples include:

- Personal assistants
- Business workflow automation
- Social impact initiatives
- Novel AI-powered experiences

Participants are encouraged to:

- Think creatively
- Focus on delivering value
- Demonstrate how agent-based systems solve real challenges
