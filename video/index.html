02 · Demo
Under the hood
graph.pyThe protocol is the topology
backend/agents/graph.py 
moderator_introduce  → [independent_eval × N]   ← parallel fan-out  → collect_independent      ← JoinNode barrier  → moderator_followup  → [discussion × N]         ← parallel fan-out  → collect_discussion       ← JoinNode barrier  → [vote × N]               ← parallel fan-out  → collect_votes            ← JoinNode barrier  → synthesizer
Three fan-out / fan-in cycles
JoinNode barriers make it structurally impossible to see round two before round one is fully collected — no contamination, even by accident.
Self-assembling graph
Built at runtime from the selected personas. Adding one is a single registry entry — no wiring.
Flash ×5 · Pro ×2
Gemini 2.5 Flash runs the participants; 2.5 Pro runs Moderator & Synthesizer. Votes return as type-safe Pydantic output.
